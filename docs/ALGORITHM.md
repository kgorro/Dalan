# DALAN: Dual-channel Agreement with Lexicon-Augmented Normalization

"Dalan" is Cebuano for road or path. DALAN decides, for each query, which path an answer takes: straight from the verified knowledge base, through a small local LLM, or to a safe abstention.

## Problem

A retrieval-first tourism assistant has three possible actions for a query q:

- SKIP: return the top-1 knowledge base entry directly. Instant and verified, but a wrong top-1 is a confident wrong answer.
- GENERATE: send q and the top-k entries to a local LLM. Can repair a wrong top-1 if the right entry is in context, but costs one to eight seconds on modest hardware.
- ABSTAIN: decline and guide the user. Safe, but a miss if q was answerable.

Two gaps make this hard in Cebu:

1. Generation skipping (Gap 1). Existing LLM routers choose between models. They rarely ask whether generation is needed at all, and they do not bound the error rate of the answers that skip generation.
2. Code-switched, low-resource queries (Gap 3). Tourists and locals write in Cebuano, Tagalog, English, and mixes ("Asa ko makapalit og danggit?", "pila ang whale shark fee for locals?"). Lexical retrieval fails on these, and a single confidence threshold tuned on English becomes over- or under-confident on them.

DALAN treats the two gaps as one problem: a confidence score is only useful for skipping if it stays reliable under code-switching.

## Method

### Stage A: Code-Switch Normalization (CSN)

For each token w of the folded query:

1. A1 Orthographic folding: lowercase, strip diacritics (Osmeña -> osmena), collapse letter runs, expand clitics and contractions (asa'y -> asa ang, unsay -> unsa ang, og -> ug), and drop function words.
2. A2 Vowel-variant keying: Cebuano e/i and o/u alternate in informal writing (komosta, kumusta). Lexicon lookup uses the key k(w) that maps e -> i and o -> u.
3. A3 Lexicon-guided affix stripping: candidate stems are generated by removing Cebuano and Tagalog prefixes (maka-, mag-, gi-, pag-, pinaka-, ...), suffixes (-on, -an, -han, -ng, ...), the Tagalog infixes -um- and -in-, hyphenation, and reduplication. A stem is accepted ONLY if it is a lexicon lemma, so English words are never altered.
4. A4 Damped concept projection: each recognized lemma l contributes its English glosses G(l) to the query with weight gamma < 1, while surface tokens keep weight 1. Damping keeps local evidence (place names, product names) dominant and limits drift from broad glosses (barato -> cheap).

CSN also outputs three code-switch statistics used later: the code-switch index CSI (share of Cebuano/Tagalog tokens among recognized tokens), the OOV rate, and the lexicon hit rate.

### Stage B: Two channels and fusion

- Lexical channel L: IDF-weighted field matching over the weighted token set (keywords x3, title x2, sample questions x1, phrase bonus, region cues).
- Character channel C: TF-IDF cosine over character 3- to 5-grams of the folded query plus glosses. Robust to typos (bantayn, osmenia) and spelling variants that L misses.
- Fusion: weighted reciprocal rank fusion F_i = sum over channels of 1 / (k + rank_c(i)), k = 10, with lexical score as tie-breaker. The top-k of F is the LLM context.

### Stage C: Calibrated confidence

A feature vector phi(q) summarizes channel strength, margins, agreement, and code-switch state:

    lex_top_sat = L1 / (L1 + 5)          lex_margin = (L1 - L2) / L1
    char_top = C1                        char_margin = C1 - C2
    agree = [argmax L == argmax C]       fused_margin = (F1 - F2) / F1
    csi, oov, log(1 + n_tokens), lex_hit
    csi * lex_top_sat,  oov * char_top,  1 / (1 + rank of L's top-1 in C)

The interaction terms let the calibrator learn that the same lexical score means less on a heavily code-switched or OOV-heavy query. A logistic model gives p(q) = P(top-1 of F is correct | phi(q)), trained on labeled calibration queries.

### Stage D: Risk-controlled, language-conditioned thresholds

Calibration queries are split into buckets g by CSI (en: CSI < 0.2, cs: CSI >= 0.2). For each bucket with enough data (else the global pool):

    tau_skip(g) = min tau  such that  precision{ p >= tau } >= 1 - eps
    tau_abs(g)  = max tau  such that  share of answerable-in-context queries with p < tau <= delta
    tau_abs(g)  = min(tau_abs(g), tau_skip(g))

Decision:

    if p >= tau_skip(g):   SKIP
    elif p >= tau_abs(g):  GENERATE with top-k fused context
    else:                  ABSTAIN

eps bounds the error rate of skipped answers, the safety-critical case. delta bounds how many answerable queries are lost to abstention. Both are operator settings, and sweeping eps traces the cost-safety curve.

### Pseudocode

    Algorithm DALAN-Route(q, KB, cal, TH)
      nq   <- CSN(q)                                   # Stage A
      L    <- LexicalScores(nq, KB);  C <- CharScores(nq, KB)
      F    <- RRF(L, C)                                # Stage B
      p    <- cal(phi(L, C, F, nq))                    # Stage C
      g    <- "cs" if nq.CSI >= 0.2 else "en"
      (ts, ta) <- TH[g]                                # Stage D
      if p >= ts: return SKIP(top1(F))
      if p >= ta: return GENERATE(q, topk(F))
      return ABSTAIN

    Algorithm DALAN-Fit(D_cal)
      for (q, gold) in D_cal: compute phi(q), y = [top1(F) in gold], c = [gold in topk(F)], g(q)
      gamma <- argmax over grid of top-1 accuracy on D_cal
      cal   <- LogisticRegression(phi, y)
      TH[g] <- (tau_skip(p_g, y_g, eps), tau_abs(p_g, c_g, delta)) for each bucket g

Routing cost is O(|q| * |KB|) and needs no neural model; measured at about 0.6 ms per query in pure Python for 52 entries. An optional dense channel (multilingual-e5) can be added as a third RRF input.

## Evaluation protocol

See experiments/run_experiments.py and results/results.md.

- Data: SugboQA-CS seed set, 246 queries (English, Cebuano, Tagalog, code-switched, and 30 out-of-domain), gold labels as lists of acceptable entries.
- Protocol: 10 x 5-fold stratified cross-validation. gamma, the calibrator, and thresholds are fit on training folds only.
- Baselines: always-RAG, prototype lexical rule, fixed-threshold hybrid, CSN plus fixed-threshold hybrid.
- Ablations: without CSN, without the character channel, without code-switch features, with global thresholds.
- Metrics: answer accuracy, wrong-answer rate, silent error rate (wrong SKIP), LLM call rate, abstention behavior, expected latency, ECE and Brier score.
- The LLM reader is modeled with stated success rates (rho = 0.9 with gold in context, rho_d = 0.7 decline rate without). Replace with measured rates from the deployed model before publication.

## Development results (seed set)

| | Accuracy | Wrong answers | LLM calls | Expected latency, CPU |
|---|---|---|---|---|
| Prototype lexical rule | 77.2% | 13.0% | 0% | about 0 s |
| Always-RAG | 77.3% | 14.7% | 100% | 8.0 s |
| CSN + fixed hybrid | 89.3% | 10.7% | 1.5% | 0.1 s |
| DALAN | 91.8% | 5.3% | 7.5% | 0.6 s |

Over the prototype, answer accuracy on Cebuano queries rises from 65% to 90% and on Tagalog queries from 65% to 95%. DALAN cuts wrong answers by about 60% versus the prototype while calling the LLM on fewer than one in ten queries.

## Threats to validity

- The seed queries were written by the developers, and the lexicon was extended while inspecting retrieval errors on the same set. Results are optimistic. A publication needs a held-out set of real tourist queries labeled by two or more annotators.
- The reader model is assumed, not measured.
- With 30 out-of-domain queries, abstention estimates have wide variance (about +/- 15 points across folds).
- Repeated-CV folds are not independent, so the Wilcoxon p-values are indicative only.
- Code-switch features improved Brier score (0.062 vs 0.082) but not ECE (0.049 vs 0.037). Their benefit is in ranking confidence, not in raw calibration; report both.
